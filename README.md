## 🎨 DevFest Nagpur Design System & Aesthetics

- 🏷️ **Warm Paper & Neo-Brutalist Layout:** Warm cream background (`#f6f1e4`) with authentic paper grain texture overlay (`.bg-grain`), bold `2px solid #141414` line-art borders, and crisp ink drop shadows (`7px 7px #141414`).
- 🎟️ **Physical Hanging Lanyard Pass:** Realistic conference badge in the Hero section complete with lanyard ribbon strap, punched clip hole, avatar, verification stamp, and vector barcode.
- 🟡 **Google Color Tokens:** Signature DevFest accents in Google Blue (`#4285f4`), Yellow (`#fbbc04`), Green (`#34a853`), and Red (`#ea4335`).
- ✍️ **Editorial Typography:** High-contrast pairing of **Fraunces** (expressive serif display) with **Space Mono** (conference ticket & terminal font) and **Inter** (clean body text).
- ⚡ **Tactile Physics & Micro-Interactions:** DevFest signature `.press` button depression, rubber stamp impact animations, and optional Web Audio API click feedback.
- 📜 **Kanban Engineering Tracks:** Domain triaged board organizing Computer Vision, NLP & OCR, and Production Cloud ML workflows.
- 🔦 **Spotlight Marquee Carousel:** Interactive horizontal scrolling card track with hover focus and backdrop blur.
- 💻 **Interactive Model Terminal Session:** Run live simulated inference tests for Vision Transformers and OCR benchmarks.
- ✉️ **Airmail Postal Envelope:** Vintage airmail striped border and Nagpur geo-coordinate stamp.
- 🌓 **Dual Theme Engine:** Toggle seamlessly between **Warm Cream Paper Edition** and **Dark Ink Edition**.

## 💻 Running Locally

No build tools or heavy node dependencies needed. Simply open `index.html` in any browser:

```bash
# Clone the repository
git clone https://github.com/Priyanshurt91/Portfolio-Website-.git

# Navigate into project folder
cd Portfolio-Website-

# Open index.html in your browser
# On Windows (PowerShell):
Start-Process index.html
```

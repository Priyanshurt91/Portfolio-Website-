## ✨ Features

- 🎨 **Modern Dark & Light UI:** Built with sleek glassmorphism, dynamic blur effects, floating background gradient blobs, and custom HSL CSS tokens.
- ⚡ **Interactive Themes:** In-memory toggle for instant switching between dark and light color modes.
- 📱 **Fully Responsive Layout:** Optimized across mobile, tablet, and desktop devices with custom navigation drawer and clean breakpoint scaling.
- ⌨️ **Dynamic Typing Header:** Animated hero header presenting key roles dynamically.
- 📜 **Smooth Reveal Animations:** IntersectionObserver-powered scroll reveal and active navigation tracking.
- 🔍 **SEO & Accessibility Optimized:** Semantic HTML5 markup, meta tags, and structured heading hierarchy.

## 💻 Running Locally

No complex dependencies or build steps required. Simply clone and open `index.html` in any modern browser:

```bash
# Clone the repository
git clone https://github.com/Priyanshurt91/Portfolio-Website-.git

# Navigate into the project folder
cd Portfolio-Website-

# Open index.html in your browser
# On Windows (PowerShell):
Start-Process index.html
```
